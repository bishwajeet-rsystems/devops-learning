# Linux Basics – DevOps Assignment

This repository contains all the source files, output artifacts, and documentation
for the Linux Basics assignment covering: file/directory management, viewing files,
searching with grep, archiving (zip/unzip), downloading with wget, permissions (chmod),
and environment variables (export).

## Contents
- `Linux_Basics_Documentation.docx` — full write-up with every command, its output, and an explanation (open this first).
- `commands_log.txt` — raw terminal transcript of every command run for this assignment.
- `test_dir/` — directory created in Task 1, containing `renamed_example.txt`.
- `test_dir.zip` — zipped version of `test_dir` (Task 4).
- `unzipped_dir/` — result of extracting `test_dir.zip` (Task 4).
- `sample.txt` — file downloaded using `wget` (Task 5).
- `secure.txt` — file with permissions set to `444` (read-only for everyone, Task 6).

## Tasks covered
1. Creating and renaming files/directories (`mkdir`, `touch`, `mv`)
2. Viewing file contents (`cat`, `head`, `tail`)
3. Searching for patterns (`grep`)
4. Zipping and unzipping (`zip`, `unzip`)
5. Downloading files (`wget`)
6. Changing permissions (`chmod`)
7. Environment variables (`export`)

See `Linux_Basics_Documentation.docx` for full command output and explanations for every task.
